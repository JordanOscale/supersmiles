# Super Smiles → GoHighLevel export

Generated by `tools/build-ghl-export.py`. Re-run it after any change to
`super-smiles-website/` — **never hand-edit the files in here**, they get
wiped on the next build.

```
python3 tools/build-ghl-export.py
```

Every file is **body markup only** — no `<!DOCTYPE>`, `<html>`, `<head>` or
`<body>`. Each one goes into a single full-width Custom Code / HTML element on
its blank GHL page.

## Which set to use

**`pages/` — use this one.** Lean markup. The CSS and JS live once in the
site-wide settings, so a style fix is one paste instead of twelve.

Three one-time pastes first:

1. `SETUP-1-head-code.html` → Site Settings ▸ Tracking Code ▸ **Head**
   (Google Fonts + the booking-gate switch)
2. `SETUP-2-custom-css.css` → Site Settings ▸ **Custom CSS**
   (all of `styles.css` + a GHL wrapper-reset block)
3. `SETUP-3-footer-code.html` → Site Settings ▸ Tracking Code ▸ **Body/Footer**
   (LeadConnector `form_embed.js` + all of `app.js`)

**`pages-standalone/` — fallback.** Same markup with the fonts, CSS, gate
script and JS inlined into every page. Use it only if the tracking-code fields
aren't available on the plan, or if a page won't pick up the site-wide CSS.
Each file is ~80KB, and a style change means re-pasting all 12.

Don't mix the two sets — a standalone page plus the site-wide footer code runs
`app.js` twice, which doubles the ticker and every click handler.

## The booking gate

On the static site one line in `assets/gate-config.js` drove the ticker on all
11 pages *and* which state `/book` rendered. Split across separate GHL pages
that single switch is gone, so flipping the site is now **two** steps:

1. In `SETUP-1-head-code.html` (head tracking code), set
   `var BOOKINGS_OPEN = true;` — this switches the ticker on every page from
   "Bookings are closed / Join the waitlist / Referrals still welcome" to
   "Bookings are open".
2. Unpublish page **07** and publish page **08** at `/book`.

Each `/book` page also stamps its own gate state in its first line of script,
so its ticker is always self-consistent even if you do step 2 before step 1.

### CTA labels

Every `/book` button currently reads **"Join Waitlist"**. Page 08 already has
the booking-era labels restored ("Book free consultation" in the nav,
"Book free call" in the sticky bar). The other 11 pages still say

| Find | Replace |

## Known caveats

- **Images are served from Vercel.** Relative paths like `assets/hero.jpg`
  can't survive the move, so all of them now point at
  `https://supersmiles-jordan-os-projects.vercel.app/assets/...`. They work
  immediately, but it's a cross-origin dependency on the Vercel project
  staying up. To move them into GHL's media library, upload the files and
  find/replace that one base URL. `ASSET_BASE` at the top of the build script
  is the single place to change it.
- **OG / Twitter images** were pointing at `www.supersmiles.au`, which
  currently serves a *different* site, so they've been repointed at Vercel too.
  Once `supersmiles.au` is actually served by GHL, repoint them at the real
  domain — social scrapers want an absolute URL on the canonical host.
- **Full-bleed sections.** The ticker, dark bands and footer run edge to edge.
  Set each GHL section holding this code to full-width with zero row/column
  padding. The `GHL COMPATIBILITY` block at the bottom of the CSS tries to
  force this, but the builder setting is the real fix.
- **Sticky nav** (`position:sticky`) breaks if any GHL wrapper has
  `overflow:hidden`. The compat block sets `overflow:visible` on the known
  wrapper classes; if the nav still doesn't pin, that's the thing to hunt.
- **SEO title, meta description, OG image and canonical** can't live in a
  Custom Code element. Each file's opening comment lists its values — paste
  them into that page's GHL settings.
- **Page-transition fade.** `app.js` intercepts internal link clicks and
  navigates via `window.location.href` after 130ms. Harmless in GHL, but it's
  why links feel slightly delayed.
- The `.mobile-cta` bar in the markup is dead — `styles.css` hides it sitewide
  with `display:none !important`. Left in place to match the source.
